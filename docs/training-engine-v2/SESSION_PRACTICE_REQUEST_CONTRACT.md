# Session Practice Request Contract

`SESSION_PRACTICE_REQUEST@1.0.0` binds request and attempt identities to athlete, Program revision,
Week plan and reservation revisions, SessionIntent, SessionSkeleton fingerprint, final prescribed
session revision, explicit mode, selection source, times, equipment, TrainingSafety, availability,
provenance, and counterfactual/applied state. It requires no free-text reason and consumes no prose.
