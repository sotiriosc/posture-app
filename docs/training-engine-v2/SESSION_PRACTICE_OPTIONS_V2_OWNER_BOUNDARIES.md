# Session Practice Options V2 Owner Boundaries

The athlete owns explicit day-of selection of `full`, `lighter`, or `recovery`. A recommendation can
suggest one mode but cannot select it. Week owns objectives, reservations, and remaining
responsibility. Session Planner and Composer own the original valid selected session.

The Session Practice Realizer may retain, omit, revise dose within an admitted policy, prune orphaned
dependencies, and emit explicit status. It cannot create a goal or weekly objective, select a new
exercise identity, diagnose, or progress a Program. Prescription owns revised blocks; Sequencing owns
the post-transformation order; Gate 13 owns planned-credit truth; Outcome Source owns performed truth;
Longitudinal may interpret repeated completed evidence only.

The Product adapter is future-only. Current routes remain historical V1. Owner-account delivery and
Product activation are not authorized.
