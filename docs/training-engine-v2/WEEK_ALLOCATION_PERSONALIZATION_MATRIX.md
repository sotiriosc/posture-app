# Week Allocation Personalization Matrix

Status: design-lab evidence, not a production behavior claim.

The fixed shell contains 18 users with the same production catalog and downstream kernels. At least the first 12 share experience and equipment while varying material weekly facts. This isolates whether a variable affects weekly intent, allocation, materialization, downstream session feasibility, or no legitimate layer.

## Material Effects

| Input difference | Expected receiver/effect |
| --- | --- |
| explicit direct-calf or assessment priority | material Weekly Intent objective difference |
| changed outcome/secondary goal priority | objective order and allocation opportunity difference through reviewed policy |
| productive prior responsibility placement | allocation continuity difference when still feasible |
| fewer/cancelled/missed opportunities | remaining allocation and explicit reallocation state |
| per-opportunity equipment or structural capacity | allocation feasibility; actual divergence triggers materialization/reallocation |
| global safety block | intent/allocation block |
| unresolved high external sport load | `unsupported_context` until a reviewed receiver exists |
| irrelevant localized pain fact | justified convergence absent a rule linking it to weekly responsibility |

The cohort produces more than four distinct intent signatures and more than four distinct allocation signatures among the first 12 same-experience/equipment users. It includes same weekly responsibility with different session placement, and same reservation with actual-day changes that require reallocation.

## Classification

Rows are classified as `MATERIAL_WEEK_INTENT_DIFFERENCE`, `MATERIAL_ALLOCATION_DIFFERENCE`, `SAME_RESPONSIBILITY_DIFFERENT_SESSION`, `JUSTIFIED_CONVERGENCE`, `REQUIRES_POLICY`, `REQUIRES_CURRENT_AVAILABILITY`, `REALLOCATION`, `WRONG_LAYER_EFFECT`, or `UNRESPONSIVE_TO_MATERIAL_INPUT`.

No cohort row is `WRONG_LAYER_EFFECT` or `UNRESPONSIVE_TO_MATERIAL_INPUT`. Convergence is justified only where inputs have no approved Week receiver. Policy/current-availability cases remain unresolved rather than inheriting profile defaults.

## Anti-Bloat

Across controlled plans, reservations never exceed opportunities, no reservation is empty, assessment activation is allocated once, and an optional direct-calf objective is allocated once. Required push/pull responsibilities survive a condensed two-opportunity case while optional calf remains `optional_not_allocated`.

## Current-Week Horizon Amendment (2026-08-12)

A 12-user same-profile cohort now varies confirmed availability, travel, equipment, cancellation, location, windows, and confirmation. Materially different current facts do not collapse to one horizon; an identical pair converges. Profile defaults remain traced tentative suggestions and create no artificial uniqueness or programming priority.
