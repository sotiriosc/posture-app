# Week Layer Fact Ownership Matrix

Status: mandatory pre-design gate, 2026-08-12. Every behavioral fact requires a legitimate giver and bounded receiver. Explanatory prose is inert.

| Fact | Giver / canonical source | Truth state / provenance | Receiver and exact bounded consequence | Absence semantics | Duplicate-consumption audit |
| --- | --- | --- | --- | --- | --- |
| planning horizon boundaries | Product Adapter or explicit coach brief | expected; source ref and evaluation time | Weekly Intent Planner and Week Allocation Composer define the ordered planning scope | current availability required | never inferred from Monday/Sunday |
| training opportunity | current-horizon schedule source | expected future fact; per-opportunity provenance | Allocation may use only available opportunities | unavailable/unknown | profile days do not duplicate it |
| opportunity minutes/capacity | horizon opportunity source | expected future fact | pre-Prescription structural feasibility only | unknown | day-of actual fact remains materializer-owned |
| opportunity equipment | explicit snapshot/reference source | expected future fact | grouping feasibility only | unknown | environment labels do not create capabilities |
| primary and secondary goals | explicit weekly brief | intended; ordered and provenance-bearing | Weekly Intent Planner normalizes context; goals alone create no objective | under-specified | phase/profile goals cannot override |
| programming context mode | explicit weekly brief | intended | preserved through reservations/directives | ordinary/no special mode | pain-aware mode is not a goal |
| weekly objective | reviewed policy, coach allocation, or explicit owner brief | intended responsibility | Week Composer allocates occurrences across opportunities | not applicable or unresolved | one stable objective, merged equivalent truth |
| objective priority/order | objective giver | intended | lexicographic weekly responsibility order | invalid if malformed | no raw-count reward |
| frequency-intent band | reviewed policy, coach, owner decision, or external brief | intended allocation opportunities | Week Composer measures allocation state only | `FREQUENCY_POLICY_REQUIRED` | never interpreted as dose/completion |
| dose-policy reference | reviewed Prescription/weekly policy owner | planned-policy reference | marks future Prescription validation boundary | unknown/pending | Week does not create sets or credit |
| recovery-spacing requirement | reviewed weekly policy | expected structural constraint | allocation rejects or marks unresolved spacing | policy required/unknown | exact post-dose recovery remains future-owned |
| assessment weekly priority | reviewed policy or explicit weekly allocation | intended, signal provenance | at most one bounded objective per coherent high-confidence cluster | context only | Session Planner prep remains separate |
| persistent restriction | explicit Safety/Clinical authority | current or horizon-scoped restriction | constrains allocation legality | unknown | transient discomfort is not promoted |
| current discomfort | athlete/current input | current observation | retained for day-of revalidation, not assumed all week | not applicable | creates no weekly objective |
| global TrainingSafety | external authority | current authority | may block executable reservations | training allowed if explicitly empty | passed unchanged |
| phase context | Phase system + reviewed policy | current developmental context | policy may influence intent while preserving structure | no direct effect | phase prose/muscles/goals do not create objectives |
| weekly continuity | prior allocation/completion evidence | historical observation | prefer stable responsibility signatures when still useful | none | split labels are never identity |
| missed/completed opportunity | completion record | completed history | reallocation decision over remaining legal opportunities | not applicable | cannot fabricate completion or double next day |
| external load event | Product Adapter/external activity source | expected or observed, explicitly tagged | unresolved or reviewed spacing/recovery receiver | unknown | prose is not parsed |
| reservation | Week Allocation Composer | planned allocation | Materializer receives one future responsibility | unallocated objective trace | not a current directive |
| actual current context | Product Adapter + Safety authority | actual current fact | Materializer compares against reservation and emits/reroutes | under-specified | expected facts cannot substitute |
| materialized directive | Session Allocation Materializer | current execution-time fact | production Session Intent Planner | no directive | materializer adds no programming policy |
| candidate/session feasibility | frozen production oracle | fixture evaluation result | Week lab accepts status only | inconclusive | no Candidate totals or Composer vectors summed |
| prescribed source exposure | future Prescription | planned dose | post-Prescription Week evaluation | pending | allocation occurrence has zero dose credit |
| completed response | performance/response receiver | observed | Longitudinal Adaptation updates future targets | unknown | cannot rewrite current history |

Any proposed fact without one of these givers and receivers remains `UNKNOWN_REQUIRES_REVIEW`, `DEFER_TO_PRODUCT_ADAPTER`, `DEFER_TO_PRESCRIPTION`, or `DEFER_TO_LONGITUDINAL_ADAPTATION`. It is not added merely to make personalization appear broader.

## Policy And Horizon Amendment (2026-08-12)

Owner decisions supply policy semantics; reviewed typed rules eventually supply executable frequency authority. Product supplies confirmed/tentative opportunities, source provenance, immutable revisions, and expected equipment. Day-of Product input supplies actual availability/equipment/safety again. Week owns objective-to-goal and reservation-to-session-goal relationships. Prescription still owns dose and Longitudinal still owns adaptation/deload authority.
