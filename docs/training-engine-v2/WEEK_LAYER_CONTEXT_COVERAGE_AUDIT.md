# Week Layer Context Coverage Audit

Status: mandatory pre-design gate, 2026-08-12.

## Represented Or Proposed Context

| Context | Rightful owner | Week-layer disposition |
| --- | --- | --- |
| explicit horizon and opportunities | Product Adapter / schedule source | required structured input; irregular ordered opportunities supported |
| weekly outcome and priorities | explicit weekly brief / reviewed policy | Weekly Intent only; no fixed split derivation |
| expected per-opportunity time/equipment | current-horizon source | reservation feasibility, never current-session truth |
| actual day-of time/equipment | Product Adapter | Session Allocation Materializer only |
| assessment | Assessment system + reviewed weekly policy | context or one bounded objective; no repeated corrective stack |
| pain | athlete/clinical source | persistent restriction may constrain; transient facts revalidated day-of |
| safety | external authority | may block all execution; never weakened by Week |
| phase | Phase system + reviewed policy | developmental context only |
| prior structure and completion | allocation/completion history | responsibility continuity and explicit reallocation |
| training response | response receiver | only reviewed longitudinal/spacing policy may consume it |
| external sport/work/load | typed Product Adapter seam | unresolved until a reviewed receiver exists |
| final dose and realized stress | Prescription | future ledger and post-Prescription validation |

## Material Missing Or Deferred Contexts

| Context | Classification | Proposed owner / safe behavior now |
| --- | --- | --- |
| exact frequency targets | OWNER_POLICY_REQUIRED | reviewed weekly programming policy; no guessed numbers |
| set/volume targets and credit ratios | HUMAN_REVIEW_REQUIRED / DEFER_TO_PRESCRIPTION | separate scientific and Prescription review |
| recovery-hour rules | HUMAN_REVIEW_REQUIRED | typed policy question; no universal hours |
| deload/reduction behavior | DEFER_TO_LONGITUDINAL_ADAPTATION | explicit future policy and response evidence |
| poor sleep / feels off | DEFER_TO_PRODUCT_ADAPTER | typed readiness seam then materialization/reallocation |
| illness | Safety/Clinical | no diagnosis; may block through explicit authority |
| accessibility/support | MISSING_CONTEXT | Product Adapter, then Candidate/Prescription receiver review |
| crowded gym | DEFER_TO_PRODUCT_ADAPTER | actual equipment snapshot; no prose inference |
| childcare/schedule uncertainty | MISSING_CONTEXT | horizon opportunity status/unresolved schedule context |
| training partner | UNKNOWN_REQUIRES_REVIEW | future Prescription/Sequencing if a bounded receiver is approved |
| two-a-day programming | OWNER_POLICY_REQUIRED | representable opportunities, unsupported allocation policy |
| competition/event taper | HUMAN_REVIEW_REQUIRED | external load/policy contract before behavior |
| return after absence | DEFER_TO_LONGITUDINAL_ADAPTATION | reviewed re-entry policy required |
| standalone recovery session | KEEP_DEFERRED | separate session-type/activity design; no production behavior |

## Coverage Verdict

The existing production domain does not represent the Week layer truthfully, so the pre-design classification is `WEEK_ONTOLOGY_FOUNDATION_GAP`. The missing contexts do not authorize silent defaults. The design lab should make policy requirements, current-availability requirements, reallocation, unresolved context, and downstream Prescription dependencies first-class results.
