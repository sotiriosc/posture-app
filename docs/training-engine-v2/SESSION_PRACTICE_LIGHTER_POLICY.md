# Session Practice Lighter Policy

`SESSION_PRACTICE_LIGHTER_POLICY_V1_STRUCTURAL_FIRST@1.0.0` implements L0-L6 lexicographically:
protect safety, legality, dominant purpose, required needs, anchors, dependencies, identity and rest;
remove zero-value optional compatibility work; omit lowest truthful optional work; omit eligible
preferred non-anchor support; then revise lower-priority developmental count within admitted bounds;
reduce a primary anchor only as a last resort; finally require a material reduction.

Blanket set subtraction, blind accessory removal, replacement, guessed load, changed reps/tempo,
shortened rest, required dependency loss, circuits, and unchanged Full mislabeled Lighter are invalid.
