# Session Practice Prescription Revision

`SESSION_PRACTICE_PRESCRIPTION_REVISION@1.0.0` is append-only and based on the source Prescription
revision. It identifies the assignment, source event, exact modified or omitted block IDs, old and new
dose facts, unchanged execution facts, policy, creation time, and final-for-execution state. Original
plans are never mutated and block ownership is never flattened. Lighter changes only an admitted count
bound; Recovery may retain only explicitly eligible blocks. Rest remains unchanged.
