# Real User Week Planning Variable Audit

Status: context coverage audit. A variable is behaviorally active only when a typed receiver and reviewed rule exist.

## Represented Receivers

The design lab catalogs 32 variables spanning explicit weekly goals/priorities, current-horizon availability, opportunity order and completion, per-opportunity equipment/capacity, prior productive structure, assessment and pain/safety references, external activity, phase, experience, programming context, and actual-day materialization facts.

Legitimate receivers are Weekly Intent Planner, Week Allocation Composer, Session Allocation Materializer, Session Intent Planner, Candidate Intelligence, Session Composer, Prescription, Longitudinal Adaptation, Product Adapter, and Safety/Clinical. The ownership matrix prevents a fact from influencing an unrelated layer merely because it is available.

## Material Findings

- Current schedule and expected opportunity facts belong to the horizon/Product Adapter, not the athlete profile.
- Actual minutes/equipment/safety belong to materialization and the existing Planner input.
- Explicit development priorities can affect Weekly Intent; catalog availability cannot create them.
- Prior productive structure can affect allocation continuity but cannot freeze a split.
- External training load needs a typed seam and reviewed consequence policy.
- Illness is Safety/Clinical context, not a heuristic allocation score.
- Poor sleep and recovery readiness require a future typed contract; absence must not masquerade as readiness.
- Deload need and response-driven target change belong to Longitudinal Adaptation.
- Accessibility and social/environmental constraints require Product Adapter contracts before behavior.

## Deferred Variables

Sleep, illness detail, acute recovery readiness, external-load magnitude, accessibility constraints, travel uncertainty, social/environmental constraints, live calendar mutations, coach overrides, deload triggers, and prescribed dose/stress are intentionally unresolved where the existing domain has no truthful receiver.

The standalone recovery-session verdict is `KEEP_DEFERRED`. An ordinary-session recovery objective does not prove a separate recovery-session type, its eligibility, downstream invariant, or dose policy.

## Scientific Review Questions

The six question families are weekly set targets, frequency superiority, recovery spacing, direct-versus-secondary credit, deload scheduling, and phase-volume adjustment. Each requires owner decision, human exercise-science review, external references, or remains unsupported. The repository does not fabricate literature.

## Evidence And Product Amendment (2026-08-12)
