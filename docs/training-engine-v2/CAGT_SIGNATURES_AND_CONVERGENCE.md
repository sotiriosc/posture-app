# CAGT Signatures And Convergence

CAGT stores separate canonical signatures for horizon, weekly responsibility, weekly allocation, reservation, materialized directive, Session Intent, Candidate legality, Candidate order/readiness, session skeleton, Prescription handoff, Sequencing handoff, response evidence, and the currently implemented pipeline. Unordered semantic collections are canonicalized; prose, labels, and scenario IDs are excluded; meaningful priority/order and behavioral ownership are retained.

Framework signature contains opportunity/reservation count, broad dominant-responsibility pattern, and stable anchor pattern. It is not a personalization score.

Classifications are `EXPECTED_CONVERGENCE`, `JUSTIFIED_CONVERGENCE`, `MATERIAL_ADAPTATION`, `OPTIONAL_VARIATION`, `DIFFERENCE_DEFERRED_TO_LATER_OWNER`, `TRACE_ONLY_DIFFERENCE_NOT_SUFFICIENT`, `SUSPICIOUS_CONVERGENCE`, `UNRESPONSIVE_TO_MATERIAL_INPUT`, `OVER_ADAPTATION`, `WRONG_LAYER_EFFECT`, and `DOWNSTREAM_RESCUE_REJECTED`.

Interpretation priority is weekly responsibilities, allocation, day materialization, session needs, candidate universe, exercise structure, support/context modification, Prescription variables, reps, then labels/prose. This is not additive scoring. Same exercise and same reps are ordinarily legal. Rep-only change can satisfy only a Prescription-owned contract that explicitly permits reps and requires no earlier response.
