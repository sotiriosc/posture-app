# Session Practice Recovery Policy

`SESSION_PRACTICE_RECOVERY_POLICY_V1_EXPLICIT_SUPPORT_ONLY@1.0.0` admits only
`recovery_support_only`, `preparation_support_only`, `activation_support_only`, and
`technique_control_observation_only` blocks with explicit structured ownership. Developmental blocks,
main strength, hypertrophy accessories, orphan main-specific preparation, and keyword-selected items
are excluded. Developmental credit and original-day completion are always zero. Empty results fail
closed as `RECOVERY_REALIZATION_UNAVAILABLE`.
