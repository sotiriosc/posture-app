# CAGT Threshold Policy

The versioned registry classifies metrics as `HARD_INVARIANT`, `WARNING`, `OBSERVE_ONLY`, `CANDIDATE_THRESHOLD`, or `NOT_MEANINGFUL`. Promotion requires owner, rationale, baseline distribution, cohort, effective version, and false-positive/negative review.

V1 hard threshold is zero for invalid fixtures, undeclared behavioral changes, prose/label effects, wrong-layer effects, accepted downstream rescue, material unresponsiveness, duplicate session identity, zero-value optional assignment, unauthorized assessment repetition, silent required omission, hidden clock/order dependence, and random output variation.

Framework collision, anchor recurrence, exact rep sameness, same-exercise rate, full-session collision, optional-accessory recurrence, and unique-program count are observed only. Low diversity is not automatically failure and no uniqueness quota exists.

Current observed metrics include framework/responsibility/allocation/session/candidate/skeleton collisions, anchor/support/exact-session/P0/optional/assessment recurrence, same-rep placeholder rate, and first-material-difference gate distribution. Unimplemented values remain null rather than fabricated.
