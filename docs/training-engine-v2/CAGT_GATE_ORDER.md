# CAGT Gate Order

The order is immutable and cannot be changed by a scenario.

| Gate | Authority | Responsibility |
|---|---|---|
| 0 | Production test integrity | Fixture diff, source, policy/catalog/time consistency |
| 1 | Design only | Weekly responsibility truth |
| 2 | Design only | Whole-week allocation coverage |
| 3 | Design only | Weekly causal adaptation and framework/content distinction |
| 4 | Design only | Duplication and distribution analysis |
| 5 | Design only | Reservation and day-of materialization truth |
| 6 | Production | Session Intent needs, priorities, sections, enrichment, continuity |
| 7 | Production | Candidate legality, pool, order, pain, phase, readiness |
| 8 | Production | Session composition, coverage, roles, anchors, redundancy |
| 9 | Handoff only | Prescription requirements and one-source-exposure preservation |
| 10 | Handoff only | Sequencing/dependency/duration handoff truth |
| 11 | Foundation only | Immutable plan, completed performance, linked response evidence |
| 12 | Mixed; reported design evidence | Repeat current gates across all horizon sessions |
| 13 | Not implemented | Post-Prescription weekly validation |
| 14 | Not implemented | Full prescribed-program causal comparison |
| 15 | Not implemented | Phase continuity decision authority |
| 16 | Foundation evidence only; decision not implemented | Longitudinal evidence/adaptation boundary |

Execution states are `PASS`, expected/justified convergence passes, rightful-owner deferral, `FAIL_STOP`, not applicable, not implemented, not reached, and shadow diagnostic only. A design pass is always `DESIGN_EVIDENCE_PASS`, never production proof.
