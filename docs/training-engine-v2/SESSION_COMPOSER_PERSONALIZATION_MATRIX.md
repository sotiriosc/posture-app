# Session Composer Personalization Matrix

The fixed-shell production matrix retains eleven one-factor users: three material session differences, three same-anchor need differences, two justified convergences, and three Prescription differences. No material input is unresponsive.

Factors are strength goal, hypertrophy goal, posture goal, shoulder discomfort, low-back sensitivity, assessment priority, productive continuity, adverse response, explicit preference, structural capacity, and high fatigue.

Availability ownership changed intentionally from the historical design lab. With identical needs, priorities, `priorityOrder`, and structural capacity, raw minute changes produce identical assignments; only duration handoff context changes. Condensed/standard/expanded differences are explicit Planner intent differences. No 45/70-minute universal admission rule remains.

Multiple productive press, row, lower-body, and supporting identities are evaluated against the need each served. Inactive anchors are not added, and one anchor cannot erase another.
