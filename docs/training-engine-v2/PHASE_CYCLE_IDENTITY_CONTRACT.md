# Phase Cycle Identity Contract

Generated deterministically from explicit Authority Registry V3 and test/developer-only Gate 15 tooling.

One Phase 1 to Phase 2 to Phase 3 developmental cycle retains one `phaseCycleId`, athlete, source program/horizon lineage, explicit createdAt, owner/source and provenance. Date, week, phase name, random UUID and completed-count derivation are prohibited. A new cycle needs a future explicit owner and a new identity.
