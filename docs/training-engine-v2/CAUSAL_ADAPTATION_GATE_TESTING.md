# Causal Adaptation Gate Testing

Status: `CAGT_READY_FOR_POLICY_ADMISSION_USE` as test/developer tooling. Version `1.0.0`.

> Causal Adaptation Gate Testing is a hierarchical counterfactual testing method in which a controlled input change is assigned to its canonical owner, the earliest layer legally permitted to respond, the latest layer by which a meaningful response is required, and the output dimensions allowed to change. Upstream invariants are protected, expected convergence is distinguished from unresponsiveness, and downstream variation cannot compensate for an earlier causal failure.

CAGT combines established ingredients including metamorphic, counterfactual, property-based, invariant, differential, deterministic-fuzz, and staged-integration testing into an owner-aware Praxis methodology. This repository records the name and method as a Praxis development result; it makes no unsupported claim that the combination is universally novel.

CAGT is not a diversity test. Different users do not inherently require different exercises, reps, frameworks, anchors, or sections. It asks whether a material fact changed the decision that fact owns, while preserving maximum justified stability and minimum necessary adaptation.

Framework structure and adaptive content are reported separately. Shared four-day or responsibility frameworks can pass. Shared adaptive responsibilities fail only when the predeclared contract requires a material response and no approved response or justified convergence exists by the latest rightful gate.

Once a gate fails, scored execution stops. Later shadow diagnostics are `INVALID_UPSTREAM_CONTEXT`, unscored, and incapable of rescue. Production, design-only, handoff-only, foundation-only, and not-implemented evidence are labeled separately.
