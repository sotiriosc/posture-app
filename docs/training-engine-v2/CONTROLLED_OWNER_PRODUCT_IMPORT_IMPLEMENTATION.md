# Controlled Owner Product Import Implementation

The adapter reads the authenticated user's current Product snapshot only after identity and mode authorization. It projects days, top-level equipment, pain regions, coarse experience, assessment references, and continuity references as structured proposed facts with explicit status.

It never silently confirms a fact, writes Product state, persists a raw snapshot, infers exact equipment, minutes, familiarity, load, recovery, readiness, or pain severity, and never treats legacy logs as V2 Performance.
