# Prescription Weekly Ledger Boundary

Week evaluation is not implemented in this task.

The later weekly ledger may view one source exposure event through several structured lenses:

- movement role
- action/function
- muscle relationship
- capacity lane
- stress exposure
- session section
- Prescription block purpose

The source exposure remains one event. The ledger must not create one event per muscle, role, need, block, or set. This task does not award direct, secondary, fractional, preparatory, or developmental weekly credit.

Preparatory acclimation blocks stay distinguishable from developmental work so H1/H2 distribution and spacing decisions can later consume truthful burden instead of prose.
