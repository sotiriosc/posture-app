# Session Intent Planner Assessment Policy

Assessment is enrichment, never session allocation.

Only a high-confidence signal with `primary` or `blocking` priority and structured relevance to an active allocated need may create a standalone Planner need. It may create at most one `preferred` preparation or activation need per coherent target, feature/action, region, and side cluster. Low- and medium-confidence signals remain context. Irrelevant high-confidence signals remain context. `weakness_development_priority` cannot create direct volume; direct hypertrophy requires an allocated directive objective.

`AssessmentSignal.actionFunctions` carries optional canonical `ExerciseActionFunction` truth. Absence is unknown, not false. Mobility and movement-limit findings can emit a typed `SessionRangeRequirement` with source signal, region, optional action and side, provenance, review status, and explanation. Dependencies retain canonical action functions rather than free-form strings.

Feature normalization is bounded to reviewed structured mappings. Description text is never parsed. Equivalent assessment clusters merge, preserving all signal and dependency references. The policy does not map one assessment to one exercise and cannot create a corrective stack.

## Coherent Session Admission Evidence

CAGT now verifies that assessment enrichment and preparation remain separate causal lanes. A populated warm-up or activation need must retain a structured relevant signal or response need plus an explicit dependency to final selected work. Equivalent signals cannot multiply objectives, and irrelevant or low-confidence context cannot create generic preparation. Empty sections remain valid.
