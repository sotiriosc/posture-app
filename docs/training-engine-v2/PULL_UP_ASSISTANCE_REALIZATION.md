# Pull-Up Assistance Realization

Contract: `PULL_UP_ASSISTANCE_REALIZATION@1.0.0`

Status: `ONE_IDENTITY_TWO_ACCEPTED_REALIZATIONS`

The canonical exercise ID is `pull-up`. Initial typed realizations are:

- `bodyweight-unassisted`, requiring an exact pull-up bar;
- `machine-assisted`, requiring exact `assisted_pull_up` capability.

Machine assistance carries an exact machine setting when supplied and otherwise remains explicitly unknown. It is not external load, no body-mass percentage is invented, and each resolution emits one source event. Assistance reduction is recorded only as a future-authority progression option. Automatic progression, automatic transition, band assistance, weighted Pull-Up, and chin-up admission counts are 0.
