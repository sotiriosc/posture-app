# Production Prescription Compiler Input

Generated deterministically from the production Prescription Compiler kernel.

`PrescriptionSessionCompilerInput` includes SessionIntent, SessionSkeleton, SessionPrescriptionHandoff, AthleteProfile, exercise and knowledge registries, EquipmentCapabilities, TrainingReadinessTrace, typed requirements, typed continuity and prior realization, completed-performance and response references, explicit executionAttemptId, explicit evaluationTime, explicit policy, and optional revision context.

Labels, tags, reason prose, source-ref text, fixture names, UI state, hidden time, and Week internals are not behavior inputs.
