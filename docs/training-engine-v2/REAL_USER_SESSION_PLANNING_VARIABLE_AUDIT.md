# Real User Session Planning Variable Audit

The adversarial cohort confirmed that explicit session purpose, outcome, current structural capacity, current equipment, structured assessment, pain/safety, and active-need continuity have legitimate receivers. It also exposed variables that the ordinary-session Planner must not guess from prose.

| Variable | Current disposition | Future owner |
| --- | --- | --- |
| poor sleep / feels off | unresolved observation | typed recovery-readiness adapter |
| illness | unsupported until typed | Safety/Clinical authority |
| accessibility or support need | unresolved | Product Adapter then Candidate/Prescription |
| crowded gym | explicit equipment snapshot required | Product Adapter |
| training with a friend | trace only | future Prescription/Sequencing review |
| wants something different | explicit request or unresolved | standalone allocation giver |
| supersets / exact flow | out of scope | Sequencing |
| standalone recovery day | ontology review required | future Week/session-type design |

Demographics, athlete label, arbitrary prose, phase prose, and generic preferences were intentionally not added as template selectors. They lack approved bounded consequences in the Planner.
