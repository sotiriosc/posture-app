# Controlled Owner Product Projection Implementation

The deterministic owner projection exposes goal and mode, Week objectives, opportunity allocations, sessions,
exercise and realization IDs, dose display values, equipment requirements, reason codes, durations, Safety,
unresolved facts, practice-mode availability, and engine/policy versions.

It is explicitly `authoritative: false`. Every displayed assignment and source event traces back to the
immutable production artifacts in the preview or envelope. The projection cannot create engine facts, alter
prescriptions, or become the source for application.
