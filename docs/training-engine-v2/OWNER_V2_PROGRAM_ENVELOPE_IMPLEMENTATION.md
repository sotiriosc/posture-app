# Owner V2 Program Envelope Implementation

`OWNER_V2_PRODUCT_PROGRAM_ENVELOPE@1.0.0` is immutable and retains preview, approval, application, profile,
Product source, legacy fallback, engine, and policy lineage. It embeds the genuine production artifacts and a
non-authoritative display projection while preserving assignment IDs, source-event IDs, Prescription revisions,
Week objectives, practice-mode references, and Phase output.

The envelope cannot overwrite the legacy Program. Exact envelope reads require user ID, envelope ID, and
envelope revision ID; no latest fallback is permitted.
