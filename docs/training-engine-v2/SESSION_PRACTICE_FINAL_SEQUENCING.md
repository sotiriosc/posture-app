# Session Practice Final Sequencing

Transformed sessions run a fresh deterministic topological sequencing pass over retained assignments
and final Prescription revisions. The pass preserves section precedence, dependency order, assignment
atomicity, block order, and sequential execution with no pairing. Existing explicit transition facts
are reused only for the same adjacency. A new adjacency or a dose revision with no recompiled timing
fact leaves the upper duration bound unknown; no time is invented. Full retains the exact source
Sequence and duration.
