# Prescription Timing Consequence Lab

Status: deterministic non-production laboratory. No numeric policy is selected.

| Scenario | Result |
| --- | --- |
| No fixed tempo | Controlled/natural intent can be expressed without numeric seconds. |
| Controlled eccentric intent | Legal for reviewed dynamic repetitions, but not a duration or hypertrophy score. |
| Exact repetition-phase timing | Legal only with explicit eccentric, lengthened transition, concentric, and shortened transition targets. |
| Lengthened or shortened pause | Must name the phase; legacy pause is ambiguous. |
| Explosive/maximal intent | Intent does not claim actual measured velocity. |
| Timed hold | Duration dose; no repetition tempo. |
| Distance vs timed carry | One carry identity; alternate trip dose, no rep tempo. |
| Steps vs duration march | Stationary march; no distance credit. |
| Breath cycles with cadence | Breath count/cadence; no rep tempo. |

Downstream rules:

- tempo-only differences cannot rescue Week, Session Intent, or Session Composer failures;
- same tempo is not lack of personalization when meaningful upstream facts converge;
- warm-up/activation duration cannot create hypertrophy credit;
- time under tension is not derived unless all repetition and phase facts are explicit.
