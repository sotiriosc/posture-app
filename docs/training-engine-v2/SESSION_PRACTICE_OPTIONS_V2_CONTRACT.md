# Session Practice Options V2 Contract

`SESSION_PRACTICE_OPTIONS_V2_BRIDGE@1.0.0` accepts only `full`, `lighter`, and `recovery` against a
complete immutable source session. Unsupported versions, incomplete Prescription or Sequence,
stale revisions, and TrainingSafety blocks fail closed. Pure identities are deterministic.

Full is exact pass-through. Lighter is structural-first and must materially reduce burden without
changing identity, necessary rest, required purpose, required dependency, or productive anchor.
Recovery is explicit non-developmental support only and never satisfies ordinary developmental Week
responsibility. The bridge has no current Product runtime authority.
