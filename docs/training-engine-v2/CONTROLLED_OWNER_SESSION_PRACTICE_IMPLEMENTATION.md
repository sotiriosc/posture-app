# Controlled Owner Session Practice Implementation

Owner Session uses the admitted `SESSION_PRACTICE_OPTIONS_V2_BRIDGE@1.0.0` production realizer. Full is the
default; a Full recommendation remains suggestion-only; the owner explicitly selects a mode. Each Full,
Lighter, and Recovery option exposes its exact availability state and reasons. No fallback changes the mode.

Mode can be revised only while pre-execution. The first Performance observation records execution start and
locks mode. Completion credits only retained performed source events; omitted assignments produce no
Performance. There is no V1 filter, automatic Week rewrite, progression, replacement, deload, or reallocation.

The Pre-G3 evidence suite remains green across 64 unique exercise identities, 64 Knowledge entries, all seven
dose modes, and the existing Product/SessionClient invariance fingerprints.
