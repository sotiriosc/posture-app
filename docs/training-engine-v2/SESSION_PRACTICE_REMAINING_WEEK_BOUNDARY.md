# Session Practice Remaining-Week Boundary

`SESSION_PRACTICE_REMAINING_WEEK_HANDOFF@1.0.0` preserves completed source events and exposes exact
unfulfilled responsibility against the original Week and reservation revisions. It may request
`remaining_week_reallocation_review`; it cannot apply reallocation, add an opportunity, move completed
work, overwrite the reservation, double work, or infer spacing from mode choice. A later authorized
Week owner must review and apply any change.
