# Session Intent Planner Personalization Matrix

The production shell covers 18 users with the same experience, normal equipment baseline, phase, catalog, and evaluation time. One factor changes per row.

| Factor | Proper effect |
| --- | --- |
| strength, hypertrophy, posture outcome | Planner outcome differs; allocation still controls needs |
| pain-aware plus strength | context differs without replacing outcome |
| shoulder pain | same purpose; relevant downstream pain evidence |
| low-back, knee, irrelevant pain | justified Planner convergence for pull allocation |
| high relevant assessment | one preferred dependent activation need |
| low relevant assessment | context only |
| productive continuity | active row identity becomes anchor evidence |
| adverse response | active row identity becomes rotation evidence |
| direct calf allocation | explicit accessory need added |
| condensed capacity | admission changes without minute threshold |
| temporary home equipment | same purpose, different Candidate feasibility |
| explicit user request | dedicated source provenance |
| missed session | no doubled needs; Week-owned context |
| no directive | explicit-allocation-required status |

The 12-row same-experience/equipment subset produces multiple truthful signatures without artificial uniqueness. Shared outputs are expected when the changed fact belongs downstream or is irrelevant to the allocated purpose. A difference is not evidence of personalization unless the fact has an approved receiver.
